# SUSHRUTA

## AI-Assisted Explainable Medical Image Segmentation

SUSHRUTA is a college mini-project focused on developing an AI-assisted medical image analysis pipeline for:

- Brain tumor segmentation from MRI using the BraTS dataset
- Breast lesion segmentation from ultrasound using the BUSI dataset

## Pipeline

Medical Image
→ Preprocessing
→ Segmentation
→ Explainable AI
→ Lesion Measurement
→ Dashboard
→ Performance Evaluation
